Understanding Australia's protected areas

This draft explores protected-area records and exotic environmental pest risks using two datasets. The charts provide an initial view of protected-area size and environmental risk categories.

Data note: The CAPAD file supplied here contains regional names, hectares and shape measurements, but no state or territory field. Therefore, the first chart ranks records by hectares instead of comparing them by state.

Interpreting the data

  • Protected-area size does not directly measure wildlife abundance or species diversity.
  • The pest dataset does not identify specific parks, so it should not be used to claim that a pest is present in a particular protected area.
  • Check the dataset documentation to confirm the geographic meaning and units of each CAPAD field.
